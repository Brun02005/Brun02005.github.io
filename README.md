# brun02005.github.io

Mi página personal: proyectos, servicios, experiencia y contacto.

**🌐 https://brun02005.github.io**

Una carta de presentación en una terminal, en blanco y negro, con referencias a Half-Life y a Steve Jobs. La música de fondo es un tema de house sintetizado en vivo con la Web Audio API: se maneja con `play`, `stop`, `drop` y `bpm 128`. Todo en un solo `index.html`, sin frameworks ni build. Links útiles: `?simple` (todo junto, sin sonido) y `#ver-acceso` (abre un proyecto). Publicado con GitHub Pages.
