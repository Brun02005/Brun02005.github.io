# brun02005.github.io

Mi página personal: proyectos, servicios, experiencia y contacto.

**🌐 https://brun02005.github.io**

Mi página de presentación: una terminal en blanco y negro con presentación, lo que hago, carrusel de proyectos y casos completos. La música de fondo es un tema de house sintetizado en vivo con la Web Audio API: se maneja con `play`, `stop`, `drop` y `bpm 128`. Todo en un solo `index.html`, sin frameworks ni build. Links útiles: `?simple` (todo junto, sin sonido) y `#ver-acceso` (abre un proyecto). Publicado con GitHub Pages.
